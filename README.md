# BrightPath Legacy Wealth Corporation - Landing Page

Official landing page for **BrightPath Legacy Wealth Corporation** (College Funding Showdown).

## 🚀 Live on Vercel

This repository is pre-configured for instant deployment on [Vercel](https://vercel.com):

1. Go to your [Vercel Dashboard](https://vercel.com/new).
2. Import the Git repository: `brightpathlegacywealth` (`https://github.com/mehdiraza-1210/brightpathlegacywealth`).
3. Leave Framework Preset as **Other** (Root directory `./`, no build command needed).
4. Click **Deploy**. Your landing page will be instantly live!

## 📁 Repository Structure

- `index.html` - Complete, mobile-responsive standalone landing page for Vercel deployment.
- `college-funding-showdown.html` - Modular HTML/CSS snippet ready to paste directly into GoHighLevel (GHL) Custom Code element.
- `brightpath-logo-transparent.png` - Transparent brand logo.
- `brightpath-logo.png` - Full brand logo with background.
- `vercel.json` - Vercel configuration for clean URLs.

## 🛠️ Embedding into GoHighLevel (GHL)

When you are ready to use this in GoHighLevel:
1. Open your Funnel / Website Page builder in GoHighLevel.
2. Add a **Custom JS/HTML** element into a full-width section.
3. Open `college-funding-showdown.html` and copy its entire contents.
4. Paste into the Custom Code editor in GoHighLevel and save.
